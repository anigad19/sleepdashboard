Connect your hardware

Each band connects through an LDC1612 to its own XIAO ESP32C3. The browser receives Bluetooth notifications from both nodes.

Firmware connection settings

Use these configurable UUIDs in both ESP32 firmwares. One notification contains one UTF-8 JSON object. Device time must be monotonic milliseconds; sequence increases by one per sample.

{"t":12500,"seq":250,"value":1048576}

Values are raw LDC readings. Set a baseline after the band is fitted. Use the same sampling rate on both nodes (target: 20 Hz). Receive-time alignment is approximate; accurate phase analysis requires firmware clock synchronization.
